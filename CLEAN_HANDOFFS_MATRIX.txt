MatrixChat -- All Confirmed Clean Handoffs So Far (Training Race)
====================================================================
Format: rows = time steps, columns = agents. "." = inactive (silent) cell.

Both examples below come from race_20260720_P_kitchen_sink's checkpoint
(and, for Example 1's exact pattern, also independently reproduced on
race_20260720_Z_pos_weight_70_plus_overlap -- same recipe family:
activity_pos_weight~0.7 + steep silence/speaker decay + handoff_bonus=0.5).

Scoring note: "clean handoff" = the first speaker (Agent 0) finishes
speaking BEFORE the listener starts, and no column ever has more than
one agent active at once (zero overlap).

CONTEXT -- how rare is this?
--------------------------------------------------------------------
A broad stochastic sweep (72 trials: 6 prompts x 4 agent-counts x 3
seeds, scripts/demo_handoff_variation.py) against this SAME checkpoint
found:
  clean_handoff_rate:          1.4%  (1/72)
  no_listener_response_rate:  94.4%

So these two examples are real, but they are NOT representative of
typical behavior -- the model produces a clean handoff only rarely
and unpredictably; it has not reliably learned this skill.
